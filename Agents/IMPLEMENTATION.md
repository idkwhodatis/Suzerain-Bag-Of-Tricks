## Commands (Windows, pwsh)

```powershell
# versions
dotnet --list-sdks
# dump dir
New-Item -ItemType Directory -Path "GameDump\<gamever>" -Force
# build (if not using VS IDE; adjust path/config)
dotnet build src\BagOfTricks -c Release -p:Platform=x64
# stage a build while the game runs (refs stay on install dir,deploy to staging)
dotnet build src\BagOfTricks -c Release -p:Platform=x64 -p:GamePath="<stage>" -p:GameRefPath="<installdir>"
```
